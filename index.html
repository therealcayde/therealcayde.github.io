Shrinking Shared Memory Without Changing Behaviour

Lower per-process memory · No regressions

The switch's shared memory structs were carrying a lot of padding the compiler had quietly added. I reordered the members for natural alignment, which brought down the memory footprint of every process. Because these structs are shared across long-running financial processes, I had to be certain the layout change had no side effects — and it didn't.
